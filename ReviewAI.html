// Architecture

Built to Scale.
Simple to Deploy.

01
Webhook Fires Instantly
When a PR is opened or pushed, GitHub/GitLab sends a webhook to ReviewAI's FastAPI server with the diff and full metadata.
02
Diff Parsed & Chunked
Changed files are language-detected and broken into semantic chunks so Claude has the right context for each analysis pass.
03
Claude AI Multi-Pass Analysis
Four specialized prompts run in parallel via asyncio — security, bugs, performance, and code quality — each tuned for precision.
04
Results Ranked by Severity
Findings are deduplicated, ranked Critical to Low, and enriched with exact line references and fix suggestions.
05
Inline Comments Posted to PR
ReviewAI calls the GitHub/GitLab Review API to post comments on exact file lines — just like a human reviewer would.
06
Team Notified via Slack
A formatted Slack message delivers the severity summary and PR link so the whole team stays informed without checking dashboards.
